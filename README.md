gro de Minecraft - Mesversario

Una página web interactiva estilo Minecraft para celebrar el 2do mes juntos. Desbloquea el logro, sube de nivel y mira la galería de fotos.

![Minecraft Style](https://img.shields.io/badge/Style-Minecraft-55FF55)
![HTML](https://img.shields.io/badge/HTML-5-orange)
![CSS](https://img.shields.io/badge/CSS-3-blue)

✨ Demo
Abre `index.html` en tu navegador. Tip: se desbloquea con el nombre `hanni`.

🎮 Características

- **Pantalla de bloqueo:** Solo se desbloquea con el nombre correcto
- **Logro estilo Minecraft:** Tarjeta de "¡Logro obtenido!" con animación
- **Barra de XP:** Se llena al 100% al desbloquear
- **Carta con efecto máquina de escribir**
- **Corazones pixelados cayendo** y partículas de XP
- **Música de fondo** (botón BGM ON/OFF)
- **Galería final** con fotos y botón para volver

🛠️ Tecnologías

- HTML5
- CSS3 (pixel-art, animaciones, estilo Minecraft)
- JavaScript vanilla
- Fuente: `Press Start 2P` de Google Fonts

🚀 Cómo usarlo

1. Clona este repositorio:
   ```bash
   git clone https://github.com/tu-usuario/tu-repo.git
2. Abre `index.html` en tu navegador
3. Escribe `hanni` y pulsa Desbloquear
4. Haz clic en "¡Obtener Logro!"
